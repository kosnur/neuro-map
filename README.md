# Нейронная карта переписки

Интерактивная карта тем и чатов ChatGPT: граф связей, поиск, просмотр диалогов, импорт экспорта и работа офлайн как приложение (PWA).

**Демо:** https://kosnur.github.io/neuro-map/

> В публичной демо-версии нет личных диалогов автора — только темы и связи. Можно нажать «Импорт истории» и загрузить свой экспорт ChatGPT (`conversations-*.json`), чтобы построить карту из собственных чатов.

## Возможности

- Граф тем: размер узла — частота, линии — связи, свечение — сила темы.
- Кружки-чаты вокруг темы: размер зависит от длины диалога, по клику открывается сам диалог.
- Поиск по темам и названиям чатов.
- Импорт стандартного экспорта ChatGPT с автоматической классификацией по ключевым словам.
- Фильтры по категориям и годам, мини-график активности по месяцам.
- Экспорт карты в JSON и PNG.
- Добавление своих узлов и связей; правки сохраняются в браузере (IndexedDB).
- PWA: установка на телефон/ПК, офлайн-режим, адаптивный интерфейс с pinch-zoom и нижней панелью диалога.

## Технологии

Чистый HTML/CSS/JavaScript без сборщиков и зависимостей: Canvas 2D, Pointer Events, WebCrypto (AES-256-GCM + PBKDF2), Service Worker, IndexedDB.

## Локальный запуск

```sh
cd public
python -m http.server 8000
# или
npx serve .
```

Откройте `http://localhost:8000`.

## Приватная версия

Личная версия с полной перепиской хранится отдельно: данные зашифрованы AES-256 и расшифровываются паролем только в браузере. В этом репозитории таких данных нет.
